Study Planner App 📚

📌 About the Project

Study Planner is a simple web application designed to help students organize their study tasks and manage their time effectively.

The application allows students to add and manage their study tasks using a user-friendly interface. It uses a backend server and a MySQL database to store task details.

🎯 Features

- Add study tasks
- Enter task title and subject
- Store task details in a MySQL database
- Simple and user-friendly interface
- Manage study activities in one place

🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL
- Development Tool: Visual Studio Code

⚙️ Installation and Setup

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Install Dependencies

Navigate to the backend folder:

cd backend
npm install

3. Configure MySQL

- Open MySQL Workbench.
- Create a database named "studymate".
- Create the required "tasks" table.
- Update the MySQL password in "db.js".

4. Run the Backend

node server.js

5. Run the Frontend

Open "frontend/index.html" using Live Server in VS Code.

🚀 How to Use

1. Open the Study Planner application in your browser.
2. Enter a task title and subject.
3. Add the task using the Add Task button.
4. View your study tasks in the application.

🎓 Project Objective

The main objective of this project is to help students plan their studies, organize tasks, and improve their time management.
